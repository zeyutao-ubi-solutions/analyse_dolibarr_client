## 重要待确认问题与来源质量

1. **合规**：未能获得实时 `robots.txt` 规则，也不能证明各底层 HTTP 请求间隔至少 1 秒。此研究恢复稿不得表述为已完成合规全量爬取。
2. **覆盖**：前次报告提到法、英、西、德、意五种语言，本清单仅能确认搜索/页面索引保留的 40 个主域名页面。是否有遗漏的语言版本文章、分页和博客需要补充检查。
3. **名称角色**：Fenotag、3A SOLUTIONS SAS、SNCF 等名称在客户、集成合作伙伴、技术合作伙伴之间的确切角色需要业务核对。Brother 是官网明确标注的设备合作方，而非目标终端客户，见其品牌产品页面。
4. **分群冲突**：零售三类、物流三类、布草链条四类，及通用制造与汽车/航空航天的层级/多标签策略需确定。
5. **推断合理性**：TGL（纺织制造）、Eaux de Zilia（灌装饮料）、Orange（电信）、Banque de France（金融）四类虽然来自客户案例，但其行业是否足够普遍，仍需商业验证。
6. **规模**：没有明确官网证据时全部记录为“无”，不能擅自用员工数设硬门槛；LinkedIn 标准行业版本也需核实。

## 分类应用规则

先识别公司**运营的业务**，再在对应细分中计算正向与排除信号。仅出现 `RFID`、`IoT`、`BLE`、`WMS`、`cloud`、`asset tracking` 等技术词，不足以确定它是 UBI 的潜在终端客户。对集成商、硬件商、咨询公司、分销商和竞品应设置独立排除/人工复核规则。
